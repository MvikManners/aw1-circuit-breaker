1. Zero-Dependency Python SDK Quickstart

Integrate Laveto Wisdom into Python applications using laveto_sdk.py:

from laveto_sdk import LavetoWisdomClient

client = LavetoWisdomClient(base_url="https://p20.laveto.net/wisdom")

# Execute an Enterprise Audit (Triggers 20% Buyback-and-Burn)
audit_result = client.audit_decision(
    dilemma_id="CEDA-AGRO-2026",
    audit_fee_bwp=35000.0,
    awt_market_price_bwp=2.50
)
POST /api/v1/aw/audit

Executes 5-Pass decision assurance and automatically processes a 20% Buyback-and-Burn on audit revenues.

Request Schema

Field Type Description
dilemma_id String Unique transaction or project identifier.
audit_fee_bwp Float Audit fee paid in BWP (e.g. 50000.0).
awt_market_price_bwp Float Current market spot price per AWT token.

POST /api/v1/aw/pouc/submit

Submits a mobile edge device micro-evaluation. Validates hardware interlocks and 3-stage PoUC Triad filters before issuing dual-token rewards.

Hardware Interlock Requirements

  • Power State: AC_CHARGING
  • Network State: UNMETERED_WIFI
  • Battery Level: ≥ 80%
  • Thermal State: ≤ 34.0°C
