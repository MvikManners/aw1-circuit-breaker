POST /wisdom/api/v1/aw/audit

Executes 5-Pass decision assurance and automatically processes a 20% Buyback-and-Burn on audit revenues.

Request Schema

Field Type Description

audit_fee_bwp Float Audit fee paid in BWP (e.g. 50000.0)[cite: 2].
awt_market_price_bwp Float Current market spot price per AWT token[cite: 2].

POST /wisdom/api/v1/aw/pouc/submit

Submits a mobile edge device micro-evaluation. Validates hardware interlocks and 3-stage PoUC Triad filters before issuing dual-token rewards[cite: 2].

Hardware Interlock Requirements

  • Power State: AC_CHARGING[cite: 2]
  • Network State: UNMETERED_WIFI[cite: 2]
  • Battery Level: ≥ 80%[cite: 2]
  • Thermal State: ≤ 34.0°C[cite: 2]
